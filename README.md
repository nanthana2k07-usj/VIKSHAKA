# VIKSHAKA

**VIKSHAKA** is an AI-powered law enforcement intelligence platform designed to enhance situational awareness, incident response, and investigative decision-making. The platform integrates real-time crime visualization, AI-assisted analytics, patrol monitoring, evidence management, and operational dashboards into a unified interface for modern policing.

---

## Overview

VIKSHAKA enables law enforcement agencies to monitor incidents, analyze crime patterns, manage investigations, and coordinate emergency responses through an intelligent and interactive dashboard.

The platform demonstrates how Artificial Intelligence, Geographic Information Systems (GIS), and real-time data visualization can support faster and more informed operational decisions.

## Installation

Clone the repository:

```bash
git clone https://github.com/nanthana2k07-usj/VIKSHAKA.git
```

Navigate to the project:

```bash
cd VIKSHAKA
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
